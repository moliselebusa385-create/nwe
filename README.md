# Lesotho Horizons Tourism Website

This project is a complete tourism website for Lesotho created as a static multi-page site using HTML, CSS and JavaScript.

## Pages
- `index.html` – Home page
- `about.html` – About Lesotho
- `services.html` – Services and travel calculator
- `gallery.html` – Image gallery with modal lightbox
- `contact.html` – Contact form with validation
- `register.html` – Registration form with validation and localStorage support

## Features
- Responsive layout for desktop, tablet and mobile
- Bootstrap 5 components and custom CSS styling
- Dark/light mode switch
- Search and filter for tourism services
- JavaScript form validation
- Gallery modal/lightbox
- Local storage integration for saved user data
- Travel budget calculator

## Run locally
Open the project folder in a browser directly, or run a local web server:

```bash
cd "C:\Users\HP\Desktop\LesothoTourismWebsite"
python -m http.server 8000
```

Then visit: http://localhost:8000
